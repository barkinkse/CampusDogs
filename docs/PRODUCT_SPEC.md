# Product specification

Campus Dogs supports anonymous campus members and authenticated university administrators. Members browse active dog profiles, public health/care information, latest known locations, public announcements, simulated nearby collar results, and can send anonymous health reports. They have no account, profile, report history, or authentication.

Admins have equal permissions: dog profiles, health records, care icons, collars, anonymous reports, private notes, announcements, and future admin provisioning. Phase 1 provides UI foundations and mock data; it excludes background location tracking, real collar integration, analytics, deployment, and member identity.
